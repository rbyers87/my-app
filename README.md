## Install Arc Raiders on iPhone

[![Install Profile](https://img.shields.io/badge/Install-iOS%20Profile-orange?style=for-the-badge&logo=apple)](https://rbyers87.github.io/my-app/MetaForge-ARC-Raiders.mobileconfig)

1. Open this page in **Safari** on your iPhone and tap the button.
2. Tap **Allow** when asked to download the configuration profile.
3. Open **Settings → General → VPN & Device Management**, tap the profile, and choose **Install**.

> The profile is unsigned, so iOS will show it as "Not Verified."
